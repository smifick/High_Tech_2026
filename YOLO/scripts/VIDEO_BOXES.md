# Фото раз в секунду: боксы и аномалии

На ноутбуке из корня проекта:

```bash
python3 YOLO/scripts/video_receiver.py --server 'http://10.11.3.178:8080/snapshot?topic=/camera_1/image_raw' --interval 1
```

По умолчанию `--capture snapshot`: отдельный HTTP-запрос JPEG и обработка моделью `best_for_classificator(2).pt` раз в секунду. Старый URL `/stream?...` автоматически преобразуется в `/snapshot?...&type=jpeg`; видеопоток не открывается. На дроне ничего менять не нужно.

Интервал отсчитывается между началами циклов. Если получение и обработка снимка занимают больше секунды, следующий запрос отправляется после завершения обработки. Параллельных запросов и очереди пропущенных снимков нет. Это целевой интервал, а не гарантия времени выполнения нейросети. Во время паузы окно обновляется и реагирует на Q/Esc; Ctrl+C завершает программу. Сетевой тайм-аут — 5 секунд.

Окно показывает последний обработанный снимок, рамки, класс и уверенность. Классы: `box_hitech` и `box_hitech_defect`. `--json-output runs/photos.jsonl` сохраняет результаты, `--output runs/last_photo.jpg` перезаписывает последний обработанный снимок. Без этих опций фотографии на диск не сохраняются.

Старый видеорежим доступен явно: `--capture stream` с URL `/stream?...&type=mjpeg`. Прежнее сопоставление ArUco: `--mode aruco`. Для GPU: `--device 0`.

Проверка без дрона:

```bash
python3 -m unittest discover -s YOLO/scripts -p 'test_snapshots.py' -v
```

## Сопоставление обоих классов с ArUco

В режиме `boxes` обе категории (`box_hitech`, `box_hitech_defect`) сопоставляются с метками по существующему правилу `shared/match_box.py`: центр метки слева от рамки, в пределах её высоты, на расстоянии до 0.9 ширины рамки; выбирается ближайшая подходящая метка. Оси считаются осями изображения (angle_deg=0). Для произвольного разворота камеры это правило нужно адаптировать. Уникальность метки между несколькими коробками не навязывается.

В `detections` добавлен `marker_id` (null, если подходящей метки нет), в корне JSON — `markers` с центрами в пикселях. На изображении показаны класс, уверенность, ID ArUco и линия связи; обычный бокс зелёный, аномалия красная. Сопоставление выполняется заново для каждого снимка, без переноса старых ID.

Словарь по умолчанию `DICT_4X4_250`; для поля с другим словарём укажите, например, `--dictionary DICT_4X4_1000`. Снимки продолжают запрашиваться раз в секунду.
