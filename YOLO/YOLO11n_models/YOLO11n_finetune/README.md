# High Tech MEPHI — обучение и дообучение YOLO11

Детектор коробок на базе **Ultralytics YOLO11n**. Проект включает обучение на исходном датасете, дообучение на объединённых данных, визуализацию результатов и создание пакета для локального запуска.

| Параметр | Значение |
| --- | --- |
| Ноутбук | `High_Tech_MEPHI_finetune.ipynb` |
| Задача | Обнаружение объектов |
| Модель | YOLO11n |
| Класс | `0 — box_hitech` |
| Среда обучения | Google Colab с GPU |
| Хранение результатов | Google Drive |

## Возможности

- Обучение детектора на основе предобученных весов `yolo11n.pt`.
- Автоматическое создание конфигурации `data.yaml`.
- Обнаружение коробок с сохранением изображений и TXT-файлов.
- Дообучение сохранённой модели на исходном и дополнительном датасетах.
- Просмотр графиков обучения, кривых качества и матриц ошибок.
- Создание архива с весами и скриптом `detect.py`.
- Формирование JSON-отчёта при локальной обработке изображения.

## Подготовка данных

Разместите архивы на Google Drive:

```text
MyDrive/
└── Colab Notebooks/
    ├── YOLO.zip
    └── extra_training_dataset_drones.zip
```

Каждый датасет должен содержать изображения, YOLO-разметку и список классов:

```text
dataset/
├── classes.txt
├── images/
│   ├── train/
│   ├── val/
│   └── test/
└── labels/
    ├── train/
    ├── val/
    └── test/
```

Для исходного архива ожидается корневая папка `YOLO`. Для дополнительного датасета используется папка `extra_training_dataset_drones`.

Содержимое `classes.txt`:

```text
box_hitech
```

Изображению `images/train/example.jpg` соответствует файл `labels/train/example.txt`. Каждая строка разметки описывает один объект:

```text
class_id x_center y_center width height
```

Координаты нормализованы относительно размеров изображения. Пример:

```text
0 0.50 0.45 0.30 0.25
```

## Запуск обучения

1. Откройте ноутбук в [Google Colab](https://colab.research.google.com/).
2. В настройках среды выполнения выберите GPU.
3. Выполните проверку видеокарты и установку Ultralytics.
4. Подключите Google Drive.
5. Распакуйте `YOLO.zip` и создайте `data.yaml`.
6. Запустите обучение.
7. Просмотрите графики и результаты детекции.

В сохранённом запуске использовалась **NVIDIA Tesla T4**.

Установка библиотеки:

## Дообучение модели

Для дообучения используются сохранённые веса первого этапа и объединённые данные.

### Порядок запуска

1. Подключите Google Drive и распакуйте дополнительный архив.
2. Проверьте структуру обоих датасетов.
3. При восстановлении среды распакуйте исходный архив блоком `old_restored`.
4. Укажите путь к исходным весам в `old_weights`.
5. Выполните блок создания итогового `combined.yaml`, который автоматически находит исходный датасет.
6. Запустите обучение из `old_weights`.
7. Откройте графики и скачайте архив результатов.

В ноутбуке также есть вспомогательные ячейки проверки данных и создания отдельных конфигураций. Итоговый запуск дообучения использует `combined_yaml`.

> При подготовке итогового объединения оставьте в `/content/datasets` одну рабочую копию исходного датасета: автоматический поиск ожидает ровно одного кандидата.

### Объединение выборок

Ноутбук проверяет совпадение названий и порядка классов. Объединение выполняется через списки путей в YAML, без копирования изображений:

```yaml
train:
  - /content/datasets/old_restored/YOLO/images/train
  - /content/datasets/extra/extra_training_dataset_drones/images/train
val:
  - /content/datasets/old_restored/YOLO/images/val
  - /content/datasets/extra/extra_training_dataset_drones/images/val
names:
  0: box_hitech
```

Конфигурация сохраняется в:

```text
/content/datasets/combined.yaml
```

| Параметр | Значение |

## Локальный запуск

Ячейка упаковки создаёт архив `box_detector.zip`:

```text
box_detector/
├── best.pt
├── requirements.txt
└── detect.py
```

В `requirements.txt` записывается версия Ultralytics из текущей среды.

### Выбор модели для упаковки

Ячейка использует переменную `best_path`. Чтобы упаковать дообученную модель, перед повторным выполнением этой ячейки задайте:

```python
best_path = new_weights
```

### Установка и обработка изображения

Распакуйте архив, откройте терминал в папке `box_detector` и выполните:

```bash
python -m pip install -r requirements.txt
python detect.py photo.jpg
```

По умолчанию используется CPU. Пример настройки порога и каталога:

```bash
python detect.py photo.jpg --conf 0.4 --output predictions
```

Для совместимой среды с CUDA:

```bash
python detect.py photo.jpg --device 0
```

### Аргументы скрипта

| Аргумент | По умолчанию | Назначение |
| --- | --- | --- |
| `image` | Обязательный | Путь к изображению |
| `--conf` | `0.25` | Порог уверенности от 0 до 1 |
| `--device` | `cpu` | Устройство обработки |
| `--output` | `results` | Каталог результатов |

После обработки создаются:

```text
results/
├── photo_detected.jpg
└── photo_result.json
```

JSON-отчёт содержит путь к изображению, признак обнаружения, число объектов, порог уверенности и список предсказаний.

Для каждого объекта сохраняются:

- `class_id` — ID класса;
- `class_name` — название класса;
- `confidence` — уверенность;
- `xyxy` — координаты рамки `[x1, y1, x2, y2]` в пикселях.

## Настройки и рекомендации

- В `old_weights` указывайте путь к нужной исходной модели.
- Для просмотра и архивирования своего запуска обновляйте `run_dir`: в демонстрационных ячейках указан конкретный каталог.
- Сохраняйте одинаковое соответствие ID и классов во всех датасетах. Основной класс проекта — `box_hitech`; вспомогательная конфигурация `data_finetune.yaml` использует подпись `box hitech`.
- Включайте оба датасета в дообучение, чтобы поддерживать качество на исходных и новых условиях съёмки.
- Для кадров одной съёмки разделяйте train, val и test по независимым сессиям.
- Подбирайте порог уверенности на валидационных данных под допустимые пропуски и ложные обнаружения.
- После перезапуска Colab повторно подключайте Drive и восстанавливайте данные в `/content`.
- Графики precision, recall и mAP используйте для оценки качества; сохранение предсказаний через `predict()` служит для просмотра обнаружений.
