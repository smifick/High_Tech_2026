# Исторический протокол проверок интеграции · 12.11.2026

Этот протокол относится к ранней версии интеграции. Числа тестов и описание
ровера ниже не являются текущим статусом. Новые результаты следует фиксировать
с хешем коммита и окружением; отсутствие полевого подтверждения в этом
протоколе не означает, что команда позднее не проводила испытаний.

Проверки выполнены в Linux, Python 3.12, CPU. Реальная аппаратура не подключалась.

| Проверка | Результат |
|---|---|
| Существующий набор `YOLO/scripts/test_*.py` | 10 тестов прошли |
| Независимые проверки `tests/test_inventory_transport.py` | 4 теста прошли: ведомость, оценка детекции, маршруты WS-клиентов и таймаут |

Актуальные команды:

```bash
python -m unittest discover -s YOLO/scripts -p 'test_*.py' -v
python -m unittest discover -s tests -v
python -m unittest discover -s web_station -p 'test_station.py' -v
```

Проверки используют имитаторы клиентов и камер, не реальные аппараты.

Это обнаруженный недостаток для выбранных снимков: правило «метка сверху»
не привязало найденные коробки к адресам. Отчёт сохраняет исходники и результаты.
Правило из последнего коммита не подгонялось под эти старые изображения;
нужно проверить текущую ориентацию камер и расположение меток на площадке.
Следствие: видимая метка без привязанной рамки может ошибочно получить «пусто».
Успешная программная интеграция не доказывает правильность ведомости.

Число найденных коробок не равно числу истинно положительных срабатываний.
Разметка, независимость кадров от обучения, точность координат и полный
полевой сценарий пока не подтверждены. Эти критерии остаются открытыми.
